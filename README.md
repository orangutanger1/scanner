# Legal Scanner
Mobile app that scans documents, automatically cleans and OCRs them, and uses an AI legal engine to summarize key points, extract important clauses, and highlight potential risks. It turns complex contracts and paperwork into clear, easy-to-understand insights within seconds.

### How to use
```
git clone ___
cd ___
bun install
bun expo start / bun run start
```
